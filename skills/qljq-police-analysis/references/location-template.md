# 地点结果模板

适用于地址、坐标、周边警情和隐患地点。

## 输出顺序

1. 地点、坐标、时间范围和半径。
2. 周边总量/风险评分/类型分布。
3. 一级、二级警情明细，重大警情优先。
4. 页面访问 URL。
