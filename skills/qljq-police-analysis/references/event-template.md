# 事件结果模板

适用于单警单、警情明细、群体性事件、涉网新平台、防汛防台和重点重复警情。

## 输出顺序

1. 查询范围和事件类型。
2. 结果概览：总数、分页范围或接口返回的状态。
3. 事件明细表；不自行从明细累加总数。
4. 空结果、分页截断、字段脱敏和工具异常说明。
